# ติดตั้งเฟส 2 — เว็บแอป TC21

ทำตามลำดับ ใช้เวลาประมาณ 45 นาที (ส่วนใหญ่คือตั้ง DataWedge บนเครื่องแรก)

## 1. อัปเดตโค้ด Apps Script (Gmail ของระบบ)

1. เปิดไฟล์ Sheets → **ส่วนขยาย → Apps Script**
2. วางทับ 3 ไฟล์เดิม: `Code.gs`, `Core` (จาก `gas/Core.gs`), `Admin` (จาก `gas/Admin.html`)
3. เพิ่มไฟล์ใหม่ **+ → Script** ตั้งชื่อ `Api` แล้ววางจาก `gas/Api.gs`
4. บันทึก แล้วกลับไปที่ Sheets → เมนู **ระบบตรวจนับ → เปิดหน้า Admin**
   ระบบจะเพิ่มชีตใหม่ (Loc_Checks, Device_Checks, Quarantine) และคอลัมน์ใหม่ใน Devices / Locations ให้เอง

> **ต้องอนุมัติ Master ใหม่ 1 ครั้ง**: รายการที่ส่งลงเครื่องตอนนี้รวมรหัสที่ไม่มีบาร์โค้ด (12 รหัส) ด้วย เพื่อให้ป้อนเองบนเครื่องได้

## 2. Deploy เป็น Web app (API ของเครื่อง)

1. ในหน้า Apps Script มุมขวาบน **Deploy (การทำให้ใช้งานได้) → New deployment (การทำให้ใช้งานได้รายการใหม่)**
2. ไอคอนเฟืองข้าง "Select type" เลือก **Web app**
3. ตั้งค่า
   - Description: `StockCount API`
   - **Execute as: Me** (Gmail ของระบบ)
   - **Who has access: Anyone** (เครื่อง TC21 ไม่ได้ล็อกอิน Google ความปลอดภัยใช้ token ของแต่ละเครื่องแทน)
4. กด **Deploy** → อนุญาตสิทธิ์ (เหมือนครั้งแรก) → คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`
5. **ส่ง URL นี้ให้ผม** ผมจะใส่ใน `app/config.json` ให้ เครื่องทุกเครื่องจะได้ที่อยู่เซิร์ฟเวอร์อัตโนมัติ

> **อัปเดตโค้ดครั้งต่อไป**: แก้ไฟล์แล้วต้อง **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ทุกครั้ง
> ถ้าแค่บันทึกไฟล์ เครื่อง TC21 จะยังใช้โค้ดเดิม (URL ไม่เปลี่ยน)

## 3. เปิด GitHub Pages

1. repo `iacheckstock-dev/stockcount` → **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: **main** · โฟลเดอร์ **/ (root)** → Save
3. รอ 1–2 นาที แล้วเปิด https://iacheckstock-dev.github.io/stockcount/app/ ต้องเห็นหน้า "ตั้งค่าเครื่อง"

## 4. เตรียมในหน้า Admin → แท็บ "เครื่อง TC21"

1. กด **สร้างรหัสเครื่อง TC21-01 ถึง 5** เครื่อง
2. **พิมพ์ป้าย** (เปิดแท็บใหม่ แล้ว Ctrl+P · ขนาดจริง 100%)
   - ป้าย Location: ใส่โซน `A,B,C,S` และเลข 1–60 (ปรับได้)
   - บัตรผู้ตรวจสอบ: จาก Staff_Code ในชีต Staff (**ต้องเป็นอักษรอังกฤษ/ตัวเลข** เช่น `EMP-NU`)
   - สติกเกอร์เครื่อง: DEV:TC21-01 … 05 แปะหลังเครื่อง
3. ลองยิงป้ายที่พิมพ์ด้วย TC21 สัก 2–3 ป้ายก่อนพิมพ์ทั้งชุด

## 5. ตั้งเครื่อง TC21 เครื่องแรก

### 5.1 ติดตั้งแอป
1. ต่อ Wi-Fi → เปิด **Chrome** → https://iacheckstock-dev.github.io/stockcount/app/
2. เมนู **⋮ → ติดตั้งแอป** (หรือ "เพิ่มลงในหน้าจอหลัก") → ไอคอน "ตรวจนับ" จะอยู่บนหน้าจอหลัก
3. **ปิด Chrome แล้วเปิดจากไอคอนเสมอ** (สิทธิ์เก็บข้อมูลถาวรได้เฉพาะตอนเปิดจากไอคอน)

### 5.2 DataWedge profile "StockCount" (ไม่แตะ Profile0)
1. เปิดแอป **DataWedge** → ⋮ → **New profile** → ชื่อ `StockCount`
2. **Associated apps** → ⋮ New app/activity → หาแอปตรวจนับ
   - ถ้าเห็นชื่อ `org.chromium.webapk.…` (แอปที่ติดตั้ง) เลือกตัวนั้น → activity `*`
   - **ถ้าไม่เห็น** เลือก `com.android.chrome` → `*` แทน (ทดสอบแล้วแจ้งผมด้วยว่าใช้แบบไหนได้)
3. **Barcode input**: Enabled
   - Decoders: เปิด **EAN-13, EAN-8, UPC-A, Code 128** ปิดตัวอื่นทั้งหมด
   - Reader params → **Picklist: Enabled**
   - Scan params → **Decode audio feedback: None** (ให้แอปส่งเสียงเอง)
4. **Keystroke output**: Enabled
   - Basic data formatting → **Send data ✓** และ **Send ENTER key ✓**
   - Key event options → **Send Characters as Events ✓**
5. **Intent output**: Disabled
6. ทดสอบเสร็จแล้ว: ⋮ → **Export profile** เก็บไฟล์ไว้ลงเครื่องอื่น (Import profile)

### 5.3 จับคู่เครื่อง
1. หน้า Admin → TC21-01 → **สร้างรหัสจับคู่** (ได้เลข 6 หลัก ใช้ได้ 30 นาที)
2. บนเครื่อง: ยิงสติกเกอร์ `DEV:TC21-01` (หรือพิมพ์) → ใส่รหัส 6 หลัก → **จับคู่เครื่อง**

### 5.4 ตรวจความพร้อม (ทุกวันก่อนนับ)
แอปตรวจ 12 ข้อและโหลดรายการบาร์โค้ดลงเครื่องให้เอง สิ่งที่ต้องทำเอง:
- ยิง **บัตรผู้ตรวจสอบ** 1 ครั้ง (ทดสอบ DataWedge + เข้างาน)
- กด **ทดสอบเสียง** แล้วติ๊ก "ได้ยินครบ"
- ตั้ง **ปักหมุดหน้าจอ** (ครั้งเดียว: การตั้งค่า → ความปลอดภัย → ปักหมุดแอป → เปิด และ "ขอ PIN ก่อนเลิกปักหมุด") แล้วติ๊ก
- ปิด **หมุนอัตโนมัติ (Auto-rotate)**: ดึงแถบบนของเครื่องลงมา แตะไอคอน "หมุนอัตโนมัติ" ให้เป็น "แนวตั้ง" แล้วติ๊ก
- ขึ้น **"พร้อมนับ ✓"** → กด **เริ่มนับ**

## 6. ทดลองนับ (ใช้รอบ 2026Q4 ทดสอบได้)

| ขั้น | ทำอะไร | ผลที่ควรได้ |
|---|---|---|
| 1 | ยิงสินค้าโดยยังไม่ยิงป้าย | จอแดง เสียงยาว "ยิงป้าย Location ก่อน" ไม่บันทึก |
| 2 | ยิงป้าย LOC:A1 แล้วยิงสินค้า 3 ชิ้น | ด้านบนขึ้น A1 · จอเขียว ปี๊บสั้น · ยอดรวม A1 = 3 |
| 3 | กดเลข 5 แล้วยิงสินค้า | +5 แล้วจำนวนกลับเป็น 1 |
| 4 | ยิงบาร์โค้ดที่ไม่มีในร้าน | จอเหลือง เสียงเตือน บันทึกไว้ |
| 5 | กด ยกเลิกล่าสุด | ยอดลดลง |
| 6 | ดู/แก้ Location → แตะ SKU → ใส่ยอดจริง | เห็นก่อน → หลัง ทั้ง SKU และ A1 ก่อนกดยืนยัน |
| 7 | ปิด Location | เห็นยอดรวมตัวใหญ่ · หน้า Admin → Location A1 ขึ้น "✓ ตรง" |
| 8 | ปิด Wi-Fi แล้วยิงต่อใน A2 | ไฟแดง ตัวเลข "ค้าง" เพิ่ม นับต่อได้ปกติ |
| 9 | เปิด Wi-Fi | "ค้าง" กลับเป็น 0 เอง · Seq ขาด = 0 ในหน้า Admin |
| 10 | สถานะ / Export → Export ไฟล์ | ไฟล์ .csv ใน Downloads · นำเข้าที่ Admin → นำเข้าไฟล์ ได้ "มีแล้ว n เพิ่มใหม่ 0" |

ถ้าขั้นไหนไม่ตรง ถ่ายภาพหน้าจอเครื่อง + หน้า Admin ส่งกลับมา

## อัปเดตเวอร์ชัน

1. Apps Script: วางทับไฟล์ที่เปลี่ยน → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
2. TC21: เมนู **⋮ → ตรวจความพร้อมใหม่** → ถ้าข้อแรกขึ้น ✗ "มีเวอร์ชัน …" กดปุ่มเขียว **อัปเดตแอปตอนนี้** (ข้อมูลในเครื่องไม่หาย)

## หมายเหตุ

- ข้อมูลการนับอยู่ในเครื่องก่อนเสมอ (บันทึกก่อนมีเสียง/จอเขียว) ถ้าเครื่องค้างหรือปิดแอป เปิดใหม่ข้อมูลยังอยู่ การ์ดจะขึ้น "กลับมาทำงานต่อที่ …" (อย่า "ล้างข้อมูล" ของ Chrome/แอประหว่างรอบ)
- ถ้าเปิดแอปแล้วขึ้น "กำลังเปิดแอป…" นานเกิน 8 วินาที กดปุ่ม **โหลดใหม่** ได้ ไม่ต้องปิดแอป
- ช่อง "ทั้งเครื่อง" แสดง SKU ของการยิงล่าสุด: **นับ** (สีเขียว) = ยอดของเครื่องนี้ทุก Location · **Stock** (สีน้ำเงิน) = ยอดบัญชีทั้งร้าน ณ สิ้นวัน D−1 (ก่อนอัปโหลด SAP เป็น "Stock(POS)") · ✓ = เท่ากัน ▲ = นับเกิน
- ถ้าเครื่องเสีย/รีเซ็ต: จับคู่ใหม่ได้ เลขลำดับจะต่อจากที่เซิร์ฟเวอร์เคยได้รับ ไม่ชนกับข้อมูลเดิม
- เครื่องที่หายหรือไม่ใช้แล้ว: Admin → **ยกเลิกเครื่อง** token เดิมใช้ไม่ได้ทันที
- ข้อมูลรอบอื่นที่ส่งเข้ามาช้าจะถูกแยกไว้ที่ชีต Quarantine ไม่รวมยอด
